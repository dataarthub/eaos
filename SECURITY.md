# Security reporting

EAOS is an experimental MIT-licensed OSS project maintained by
[dataarthub](https://github.com/dataarthub) alone. It is provided as-is, without
warranty. There is no guaranteed support, acknowledgement, response time, fix,
backport, compatibility period or ongoing monitoring service for any version.
There is no substitute maintainer.

## Private reports

If you choose to report a vulnerability, use
[GitHub private vulnerability reporting](https://github.com/dataarthub/eaos/security/advisories/new).
Include the affected package/version and a minimal sanitized reproduction.
Do not post credentials, customer data or exploitable details in public Issues.
Reports may wait or receive no response when the maintainer is unavailable.

The maintainer decides whether and when to investigate or address a report, taking
severity, actual exposure and available capacity into account. No fixed triage or
remediation deadline is promised. If a fix is released, the normal verified release
process and sanitized upgrade guidance apply. Old versions have no backport promise.

## Compatibility and ordinary questions

Pre-1.0 minor versions may introduce documented breaking changes. Review each
package's changelog before upgrading. Production hosting, tenant security and
rollout decisions belong to the consuming host.

Non-sensitive bug reports and questions in English are welcome in
[GitHub Issues](https://github.com/dataarthub/eaos/issues); this is not a support SLA.
The reporting channel and this document do not add a maintenance obligation or
change the MIT license terms.
