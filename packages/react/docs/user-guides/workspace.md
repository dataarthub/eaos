# Use the workspace

## Prerequisites

Sign in through the method supplied by your administrator and confirm your selected organization and account. Menus show available entrypoints; every operation still checks current permission.

## Step-by-Step Implementation

1. Review memberships and invitations, then choose the intended organization. Do not reuse another account's previous input or display state.
2. Select a record and confirm its name, period and status. Compare related records by their displayed details. A first page of results does not represent the entire catalog.
3. Choose the operation, enter required fields and save. Typed input is not saved data; after confirmation, reload to verify the result. A preview does not publish or commit a business decision.
4. If a stale revision is rejected, reload and compare the latest changes before trying again. Check the actual outcome before repeating an uncertain external send or payment.

## Verification

Confirm the selected organization, the saved status and the refreshed record. For AI chat, review the sources and organization scope. An answer does not prove that spending, contracts, publication or delivery occurred.

## Troubleshooting / Common Pitfalls

Ask an administrator about unavailable login, membership or operations. Missing configuration/data/calculation does not mean success or zero. Never paste credentials into business fields. Read each feature's help for its business-specific conditions.

Developers configuring this screen should use the [host integration guide](../guide.md) for package imports and host requirements.
