# ワークスペースの使い方

## 前提条件

対象の機能・組織に対する現在の権限と、必要なホスト接続を確認します。実環境の資格情報を業務入力に含めないでください。

## 手順

### ログインと所属

管理者から案内されたログイン方法で接続し、現在選択している組織と自分のアカウントを確認してください。「所属・招待」では参加する組織と招待を確認します。画面のメニューは自分に利用を許可された機能を開く入口です。メニューが見えても、操作権限が付与されたとは限りません。

アカウントを切り替えた後は、以前の組織の入力・表示を使い回しません。ログインできない、組織を選べない場合は、認証・招待・現在の所属を管理者へ確認してください。パスワードや認証情報を業務の入力欄へ貼り付けません。

### 一覧と詳細を使う

一覧から対象を選び、名前・対象期間・状態を確認して詳細を開きます。関連する物件・取引先・施設などは、候補の表示名と内容を照合して選びます。検索や次のページがある場合、画面に出た先頭の件数を全件数と読み違えません。

### 入力と保存

「実行する操作」で目的の操作を選び、必要な項目を入力して保存ボタンを押します。入力途中の文字は保存済みではありません。「保存しました」と表示された後に再取得して結果を確認してください。プレビューは確認用で、保存や公開と同じではありません。

別の担当者が先に変更した場合、古い画面からの保存を拒否することがあります。最新状態を再取得し、変更内容を照合してからやり直します。結果が不明な外部送信・決済は、同じ操作を繰り返す前に処理状況を担当者へ確認してください。

### 使えない操作とAI

利用権限・接続・対象の状態によって、ボタンを表示しない、押せない、操作を拒否することがあります。管理者へ対象機能とエラーの状況を伝えてください。未接続・未取得・未算出は成功やゼロを意味しません。

AIチャットが接続されている環境では、上部のチャットボタンで開閉します。回答の根拠と対象組織を確認してください。回答だけで支出・契約・公開・外部送信を実行済みとは扱いません。各業務の具体的な条件は、その画面のヘルプを読んでください。

## 確認方法

保存結果や最新状態を再取得し、対象と結果を確認します。ローカルの成功、スキーマ適用、実組織での受入は分けて記録します。

## 問題が起きたとき

競合・権限失効・未接続の場合は最新状態とホスト設定を確認します。結果が不明な外部操作を自動で再送しないでください。
