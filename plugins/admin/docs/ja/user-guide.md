# 操作監査

## 前提条件

対象の機能・組織に対する現在の権限と、必要なホスト接続を確認します。実環境の資格情報を業務入力に含めないでください。

## 手順

管理者は現在の組織で許可された業務を選び、操作・実行アカウント・日時・記録のハッシュを確認できます。「次の監査履歴」で続きを読み、「履歴と実行記録の整合性を確認」で現行記録の連続性と保存済みの実行記録を照合します。再読込しても保存済みの履歴を確認できます。

業務本文や秘密情報は表示しません。履歴の検証はデータベース内の整合性確認であり、外部の改ざん防止証明ではありません。旧記録はこの検証の対象外です。権限・有効状態が変わった場合や検証に失敗した場合は表示を消し、確認できなかったことを示します。データ編集・削除・任意SQL実行は提供しません。

## 確認方法

保存結果や最新状態を再取得し、対象と結果を確認します。ローカルの成功、スキーマ適用、実組織での受入は分けて記録します。

## 問題が起きたとき

競合・権限失効・未接続の場合は最新状態とホスト設定を確認します。結果が不明な外部操作を自動で再送しないでください。
