# 追加項目の設定

## 前提条件

対象の機能・組織に対する現在の権限と、必要なホスト接続を確認します。実環境の資格情報を業務入力に含めないでください。

## 手順

組織の業務に必要な項目の定義を設定する管理者向け機能です。項目名・データの種類・必須条件を確認して保存します。表示名を変えても、すでに保存された業務データを自動で別の意味へ変換するものではありません。

本当に必要な項目か、入力担当者が意味と単位を理解できるかを確認してください。必須にするときは、対象画面と既存データへの影響を担当者と確認します。保存した設定と、個々の業務レコードの保存は別の操作です。

操作には現在の組織の権限が必要です。更新競合・権限変更・機能停止で保存できない場合は、画面を再取得して状態を確認します。別組織の項目や任意のデータベース列を直接変更する画面ではありません。

### 対象と項目の選択

最初に設定対象の業務を選び、その対象で許可された項目を選びます。「表示名」「入力例」「補足」を保存し、再取得して変更を確認してください。必須の基本項目は非表示にできません。型や基本の必須条件も変更できません。表示設定を利用する業務画面では表示名・入力例・補足が反映され、保存内容や検証ルールは維持されます。

## 確認方法

保存結果や最新状態を再取得し、対象と結果を確認します。ローカルの成功、スキーマ適用、実組織での受入は分けて記録します。

## 問題が起きたとき

競合・権限失効・未接続の場合は最新状態とホスト設定を確認します。結果が不明な外部操作を自動で再送しないでください。
