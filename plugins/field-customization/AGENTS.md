# @alneas/eaos-plugins/field-customization

MIT public plugin. Use public EAOS contracts and external Appkit Core/React 0.2.0 only. Keep tenant/resource authorization, CAS, durable audit and migration identities. No private imports or business-specific presets.

This feature is owned by the single `plugins/package.json` distribution, `@alneas/eaos-plugins`. Keep feature source, tests, guides and isolated runtime/frontend outputs here; do not add a feature-level package.json or root runtime barrel. Use the logical module selector `@alneas/eaos-plugins/field-customization` for inventory and host selection. Selection does not enable tenants.
